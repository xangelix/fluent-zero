# Security Policy

## Supported Versions

`fluent-zero` and `fluent-zero-build` are pre-1.0. Security fixes are released
for the latest published `0.x` version only; please upgrade to it before
reporting.

| Version       | Supported |
| ------------- | --------- |
| latest `0.x`  | yes       |
| older         | no        |

## Reporting a Vulnerability

Please do **not** open a public issue for security problems.

Report vulnerabilities privately through GitHub security advisories:
<https://github.com/xangelix/fluent-zero/security/advisories/new>
(repository **Security** tab, then **Report a vulnerability**).

Include the affected crate and version, a description of the impact, and a
minimal reproduction (for example the `.ftl` input or calling code) if you
have one. You will receive an acknowledgement, and the fix and advisory will
be coordinated with you before public disclosure.
